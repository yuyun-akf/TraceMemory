# SillyTavern／SillyDroid 实机验收

## A. 安装与生命周期

- [ ] 扩展管理器显示“留痕记忆 TraceMemory 0.1.0-alpha.1”。
- [ ] 启用后设置面板只出现一次。
- [ ] 重载后设置仍在，控制台无重复监听报错。
- [ ] 禁用后提示注入清空、设置面板消失，正文和记忆数据不被删除。
- [ ] 再启用后当前聊天记忆仍可读取。

## B. 环境自检

- [ ] `readiness.core=true`。
- [ ] 同轮／混合模式前 `readiness.inline=true`。
- [ ] 后台／混合模式前 `readiness.background=true`。
- [ ] 自动隐藏前 `readiness.autoHide=true`。
- [ ] 报告只列接口名和版本，不含聊天正文或 API Key。

## C. 同轮随写

- [ ] 一个有效剧情回复增加恰好一条短期记忆。
- [ ] 纯 OOC 不增加。
- [ ] `<TraceMemoryUpdate>` 在消息渲染前消失，重载后也不出现。
- [ ] 漏包只进入“待补写”，没有额外网络请求。
- [ ] 第 15 条同轮生成一批长期记忆与日记。

## D. 后台与混合

- [ ] 后台模式每个待处理角色回复最多一次静默请求。
- [ ] 静默结果不成为聊天楼层，不再次触发记忆处理。
- [ ] 混合模式普通轮无额外请求，满批时一次静默归档。
- [ ] 后台失败时保留短期记忆和正文，不隐藏来源。

## E. 隐藏所有权

- [ ] 归档元数据保存成功前没有消息变为 `is_system=true`。
- [ ] 自动隐藏不碰索引 0，也不碰“保留最近消息”窗口。
- [ ] 在已有长聊中首次启用，只隐藏启用后已被本扩展归档的楼层，不触碰此前历史。
- [ ] 第二批归档会继续推进第一批留下的可见尾部，不出现永久漏藏区间。
- [ ] 已由用户手动隐藏的消息不获得扩展标记。
- [ ] “恢复”只解除带扩展标记的消息。
- [ ] `/hide` 或核验失败后，面板报告错误，没有伪报成功。
- [ ] `/hide` 部分成功时会尝试 `/unhide` 回滚；未能回滚的消息保留扩展所有权标记，仍可点击“恢复”重试。

## F. 变更与隔离

- [ ] 切换聊天后数据不串台。
- [ ] 编辑、删除或重roll未归档当前批消息时可安全替换或提示。
- [ ] 编辑、删除或重roll已归档来源时触发安全锁，并恢复本扩展隐藏楼层。
- [ ] 群聊中不写入、不注入、不隐藏。
- [ ] 同时开启卡内旧记忆规则时有可见冲突迹象；正式使用前关闭其中一套。
