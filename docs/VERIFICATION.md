## 已覆盖的回归场景

- 合法、残缺记忆包的剥离与解析。
- 精确满批归档，下一批记录不被吞掉。
- 永久事实去重。
- 当前批回复重 roll 时，旧短记忆及其承诺／礼物一并撤销。
- 已归档消息、前置 user 消息编辑／删除／重 roll 的来源漂移检测。
- 安装到已有长聊时不越过 `captureStart` 隐藏旧历史；多批归档连续推进隐藏游标。
- 同轮、后台、混合三种模式提示契约与认知边界。
- 损坏元数据的数值夹取与数组整理。
- quiet／impersonate 生成不请求同轮记忆包。
- 无宿主环境导入与生命周期导出。
- 设置页与正文栏使用同一组稳定记录定位器；短记忆、长期事项和归档的人工修改会直接改变下一轮提示读取的聊天元数据。
- 同一批归档只保留一个权威记录描述，但可映射到该批每个来源楼层；任意映射位置修改的都是同一归档对象。
- 新旧聊天状态都能补齐正文栏显示开关，且没有 `localStorage`、`sessionStorage` 或 IndexedDB 形式的影子记忆库。
